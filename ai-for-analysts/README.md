# Выручка интернет-магазина

Магазин сравнивает октябрь и ноябрь 2025 года. Все записи вымышлены. Для работы понадобятся SQLite и терминал. Скачайте каталог вместе с репозиторием и откройте новую базу.

```sh
git clone https://github.com/hexlet-components/data-datasets.git
cd data-datasets/ai-for-analysts
sqlite3 shop.db
```

В консоли SQLite загрузите выгрузку один раз в пустую базу.

```text
.read setup.sql
.headers on
.mode column
```

В таблице `orders` одна строка соответствует заказу. Поле `ordered_on` хранит дату заказа, `channel` указывает канал продажи. В `items` позицию задаёт пара `order_id` и `line_no`. Сумма `amount` дана за всю позицию в рублях. Каждая запись в `refunds` содержит сумму одного возврата по заказу. Для сравнения магазин относит возврат к дате исходного заказа.

## Сведения владельца выгрузки

Снимок подготовлен 30 ноября. Октябрь закрыт целиком. В ноябре переданы заказы по 24 число включительно. Для попавших в выгрузку заказов переданы все позиции и известные на дату снимка возвраты. В двух позициях при выгрузке потерялась сумма. В файле [source-check.csv](source-check.csv) приведён ответ владельца после сверки этих позиций с источником.

Для сверки с решением откройте вторую пустую базу командой `sqlite3 reference.db`. Выполните в ней сначала `.read setup.sql`, затем `.read solution.sql`. Вторая команда создаст представления `checked_items` с восстановленными суммами и `order_revenue` с выручкой каждого заказа. Таблицы выгрузки сохранят исходные значения.

Для анализа обращений используйте [messages.csv](messages.csv). Обращения составлены отдельно от заказов. У наборов нет общего идентификатора клиента.
